# 人工智慧最新研究進展 (2024 Q1)

## 1. Google DeepMind: Gemini 1.5 Pro
Google DeepMind 於 2024 年 2 月發布了 Gemini 1.5 Pro。
- **核心突破**: 支援高達 **100 萬 token** 的 Context Window (上下文視窗)。
- **能力**: 能夠一次處理大量的文字、程式碼庫、甚至長達數小時的影片資訊。
- **架構**: 採用了 Mixture-of-Experts (MoE) 架構，提升了訓練與推論的效率。

## 2. NVIDIA Blackwell 架構 (B200)
在 GTC 2024 大會上，黃仁勳發表了新一代 GPU 架構 Blackwell。
- **規格**: B200 GPU 擁有 2080 億個電晶體。
- **效能**: 專為兆級參數 (Trillion-parameter) 的 AI 模型訓練與推論設計，效能較 H100 大幅提升。
- **應用**: 旨在推動 Generative AI 的下一波工業革命。

## 3. Meta Llama 3
Meta 推出了 Llama 3 開源模型系列。
- **特點**: 在推論速度與程式碼生成能力上有顯著提升。
- **訓練**: 採用了更有效率的訓練架構與更大規模的高品質資料集。
- **開源影響**: 持續推動 AI 社群的開源創新與應用落地。

## 4. Agentic Workflow (代理工作流)
Andrew Ng (吳恩達) 提出 AI Agent 的發展趨勢。
- **概念**: 從單純的 Chatbot 轉向 Agentic Workflow。
- **模式**: 包含 Reflection (反思), Tool Use (工具使用), Planning (規劃), Multi-agent Collaboration (多代理協作)。
- **優勢**: 透過迭代與分工，能解決比單次 Prompt 更複雜的任務。
